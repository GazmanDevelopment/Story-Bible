Story Bible

Install the Word task-pane add-in on this computer.

Download manifest.xml
  1. Click the button above and save manifest.xml somewhere you'll find it (e.g. Downloads).
  2. Open Word, then go to Insert (or Home) → Add-ins → More Add-ins.
  3. Switch to the My Add-ins tab and click Upload My Add-in.
  4. Browse to the manifest.xml you just downloaded and confirm.
  5. Story Bible now appears as a button on the Home tab.

This manifest points at the private storybible.huscroft.com.au server - it only works for accounts already permitted there. No add-in files or story content are hosted on this page, just the small XML file Word needs to find the add-in.
